# 리포트 뼈대

각 절의 존재 이유를 함께 적는다. 이유가 사라진 절은 빼도 된다.

---

## 상단 — 먼저 읽어주세요

**한 줄 답변부터.** 요청자가 첫 문장에서 답을 얻어야 한다.
"요청하신 X는 <최신연도> 기준 <수치>입니다. 공식 출처는 <기관>입니다."

### 요청 대비 결과

| 요청하신 것 | 결과 |
|---|---|
| … | **완료** / **일부** / **불가** + 한 줄 사유 |

충족 못 한 항목을 숨기지 않는다. 첫 화면에서 알아야 요청자가 다른 경로를 찾을 수 있다.

### 인용하실 때 주의사항

**이 절이 리포트의 실질적 기능이다.** 검색하면 나오는 틀린 수치를 미리 차단한다.

- 오래된 수치가 검색 상위에 있는 경우 → 연도와 함께 명시
- 분모가 다른 수치가 함께 도는 경우 → 어느 것을 쓸지 지정
- 원출처 불명 수치 → 사용 금지로 못박음
- 국제 비교 시 연도 규칙

### 함께 드리는 것

`그래프/`, `원문/`, `_작업용/`이 각각 뭔지 한 줄씩.

---

## 요약

3~4개 문장. 각 문장은 근거 절 번호를 품는다. **불가능한 항목이 있으면 여기에 포함한다.**

---

## 본문

1. **국내 현황** — 시계열 표 + 라인 그래프 + 출처 블록(통계명·작성기관·수록기간·공표주기·지표 정의) + 교차 검증
2. **세부 분해** — 연령별·기관별 등. 그룹 막대. "전체가 아니라 어디가 올랐나"를 보여준다
3. **왜 문제인가 — 결과 지표로 검증**
   이 절이 없으면 리포트는 주장이지 근거가 아니다. 첫 문장은 "이 수치가 높다는 것 자체는 문제가 아니다"로 시작한다. 검증하는 절이지 규탄하는 절이 아니다.
   - 3.1 국제기구 공식 입장 — **원문 PDF에서 직접 인용.** 문서번호·발행일 명시
   - 3.2 국가 단면 (과정 지표 × 결과 지표 산점도) — 전체 표본과 층화 표본의 상관을 **둘 다** 제시. 소득 교란을 밝힌다
   - 3.3 반박하기 어려운 1:1 비교 — 인구구조·의료전달체계가 유사한 나라 하나를 골라 붙인다
   - 3.4 분모 함정 — 이름이 비슷한 지표들의 분모를 표로 갈라놓고, 분자 원수치를 병기한다
   - 3.5 **이 절의 한계** — 단면은 인과가 아니라는 것, 보정하지 않은 것, 출처 간 불일치, 못 한 분석을 적는다
4. **국제 비교**
   - 4.1 국제기구 공통 기준 (순위·평균) — 연도 명시
   - 4.2 각국 자체 통계 최신치 (수준·방향) — 순위 매기지 않음
   - **두 시점 사이 격차 변화를 계산해 명시한다**
5. **지표 공백** — 요청받았으나 존재하지 않는 지표. 왜 없는지, 국제 표준에는 있는지, 대체 근거는 무엇인지
6. **정책 비교** — 변곡점의 제도 / 저성적·고성적 국가의 공통 제도 / 정리 표
7. **임상·전문 가이드라인** — 기관·문서·발행연도·접근 조건
8. **첨부 원문** — 무엇이 들어있고 저작권 조건은 무엇인지. **본문 주장과 충돌하지 않는지 확인한 뒤 넣는다**

---

## 부록 A — 출처 목록

확인 상태 표기 설명을 먼저 넣고, 분야별 표로. 각 행: 출처 / 확인 상태 / 비고.
**"사용 금지"인 출처도 행으로 남긴다.** 요청자가 나중에 그 수치를 만났을 때 판단할 수 있어야 한다.

## 부록 B — 이 문서의 검증 상태

| 구분 | 내용 |
|---|---|
| 1차 출처 확인 | … |
| 2차 인용 | … |
| 미확인 | … |
| 계산으로 산출한 값 | 우리가 원자료에서 직접 계산한 것. **재현 스크립트 경로를 함께** |
| 방법론상 한계 | 보정하지 않은 교란, 인과로 읽으면 안 되는 부분 |

보통 리포트에는 "확인 안 했음"을 쓰지 않는다. 하지만 틀린 수치가 검색 상위에 도는 주제라면 요청자가 스스로 판단할 수 있게 하는 편이 낫다.
